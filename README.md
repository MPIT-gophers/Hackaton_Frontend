# Hackathon template

Личный стартовый репозиторий для хакатонов: отсюда удобно **копировать готовые куски** — компоненты UI, хуки, утилиты, конфиги — в новый проект под конкретное задание.

## Зачем это

- Не начинать с нуля: держать проверенные паттерны в одном месте.
- Быстро собрать скелет приложения: взять папку/файл из этого репо и вставить в рабочий проект.
- По желанию: форк или `git clone` → вырезать нужное → идти дальше.

## Как пользоваться

1. Склонируй или скопируй репозиторий.
2. Найди нужный модуль (компонент, хелпер, пресет линтера и т.д.).
3. Скопируй файлы в целевой проект, поправь импорты и зависимости под его стек.

При необходимости заведи здесь **ожидаемую структуру** (например `components/`, `hooks/`, `lib/`) и наполняй по мере готовности блоков.

## Что можно хранить здесь

- Переиспользуемые React/Vue/Svelte-компоненты и стили.
- Обёртки над API, типы, схемы валидации.
- Конфиги: ESLint, Prettier, TypeScript, CI.
- Сниппеты и мини-библиотеки без привязки к одному хакатону.

## Лицензия

Укажи свою лицензию или оставь только для личного использования — как решишь для своих проектов.
